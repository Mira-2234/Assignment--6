🛠️ DigiTools Platform

A sleek and user-friendly digital marketplace designed for discovering and purchasing high-quality digital products. From AI-powered writing tools to creative design templates and stock resources — everything is organized in one place for a smooth browsing experience.

---

🚀 Tech Stack

* React.js
* Tailwind CSS
* JavaScript
* React Toastify
* Lucide React
* React Icons

---

✨ Key Features

🛒 Smart Cart System

Easily add or remove products from your cart with automatic price calculation for a seamless checkout experience.

🔍 Advanced Product Browsing

Explore a wide range of digital tools with intuitive filtering based on categories like *Best Seller*, *Popular*, and *New Arrivals*.
🔔 Real-time Notifications

Receive instant and visually appealing toast alerts for actions like adding or removing items from the cart.

---
🌐 Purpose

DigiTools Platform aims to simplify access to premium digital resources by providing a clean, fast, and engaging user experience for both browsing and purchasing.
